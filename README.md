# 🌙 For My Kolchuma

Curated & verified halal events for Muslim families in East London.

**60+ events** · Map view · Halal restaurant finder · Distance from home · No alcohol · No nightlife

## Features

- **Weekly event browser** with filters by category, region, free/paid, baby/child-friendly
- **Map view** with all events plotted on interactive Leaflet map + home marker (IG11)
- **Sort by nearest** — distance calculated from IG11 9TJ
- **Halal restaurant finder** — AI-powered, finds nearby halal restaurants for any event
- **What to Watch** — curated streaming & cinema picks
- **Community sources directory** — 18 verified platforms for finding more events
- **AI-powered Discover More** — searches Meetup, Eventbrite, community groups in real-time

## Deploy to GitHub Pages

1. Fork or create a new repo
2. Copy `index.html` to the repo root
3. Go to **Settings → Pages**
4. Set source to **Deploy from a branch → main → / (root)**
5. Save — your site will be live at `https://yourusername.github.io/repo-name/`

## Deploy to Cloudflare Pages

1. Push this repo to GitHub
2. Go to [Cloudflare Pages](https://pages.cloudflare.com)
3. Connect your GitHub account
4. Select this repo
5. Build settings:
   - **Framework preset**: None
   - **Build command**: (leave empty)
   - **Build output directory**: `/`
6. Deploy — live in ~30 seconds

## Tech Stack

- React 18 (CDN)
- Babel Standalone (JSX compilation in browser)
- Leaflet + CartoDB tiles (map)
- Anthropic API (AI features — halal finder, discover more)
- Zero build tools — single `index.html` file
